## URL Shortener

A simple URL shortener service built with Node.js and Express. This service allows users to shorten long URLs and provides a unique short URL that redirects to the original URL.

### Features
- Shorten long URLs to a unique short URL.
- Redirect short URLs to the original long URL.
- Store URL mappings in memory (for demonstration purposes).
- Basic error handling for invalid URLs.
- Simple and easy-to-use interface.
