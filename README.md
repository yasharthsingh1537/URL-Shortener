# 🔗 URL Shortener

A simple and efficient URL Shortener that transforms long URLs into short, shareable links. Built as a learning project inspired by **RoadsideCoder**, this project explores URL shortening, backend development, database integration, and URL redirection.

## ✨ Features

- 🔗 Convert long URLs into short links
- 🚀 Redirect short links to their original URLs
- 📋 Generate shareable links with ease
- 💻 Clean and user-friendly interface

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Styling:** Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Tools & Libraries:** Supabase, Vite, React Router

## ⚙️ How It Works

1. Enter a long URL into the application.
2. Generate a shortened URL.
3. Copy and share the shortened link.
4. Open the short link to get redirected to the original URL.

## 📚 What I Learned

- Understanding how URL shortening works
- Building backend APIs with Node.js and Express.js
- Implementing URL redirection and routing
- Working with PostgreSQL and Supabase
- Developing a full-stack application using React
